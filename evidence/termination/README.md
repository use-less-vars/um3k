# The termination build: three runs, one script, one grader

Three runs share one code shape — `run_build_A.py`, where line length, load position and load value are **flags, not code paths** — and one grader, `grade_2b.py`, which reads the artefacts rather than any number retyped here. **Run A** (`--n-line 54 --load-at-mm 20 --load-ohm 50`) is the graded run: a 62 x 206 x 22 = **280,984** cell grid (nx = n_pml 6 + n_ref 2 + n_line 54; ny = 2\*n_pml 12 + n_strip 2 + 2\*n_clean 192; nz = n_sub 4 + n_air 12 + n_top 6 — n_top equals n_pml, so the zmax face is a matched layer and not a lid, the same lid-on-lid arrangement the validated `evidence/board_poc/A_microstrip.json` run records as "62 x 44 x 22 cells at 0.4000 mm" with `values.npml` 6), dt 7.626299478123987e-13 s, 2400 steps — the corrected price, since the 68 x 218 x 28 = 415,072 figure an earlier revision carried was borrowed from `evidence/h_refine/h040.json` and belongs to the eigensolver ladder row, not to this run, and the n_top 12 that revision also carried came from the same file (`rungs[0].n_top` 12, whose own `npml` is 12 because its PML is 4.8 mm at a 0.4 mm cell: copying the lid without the matching laterals is what threw the ValueError at `emfit/studies.py:2557`) — and it closes **AC-3** (|S11| <= 1.0e-3, ||S21| - 1| <= 1.0e-3), **AC-6** (load value, units, kind, position and the S-parameter plane index all in the artefact, re-derived by the grader rather than copied) and the **magnitude half of AC-5**; **Run E** (`--n-line 79 --load-at-mm 30 --load-ohm 50`, 87 x 206 x 22 = **394,284** cells, +40.3 %) supplies the second length, and A**+**E together — and only together — close **AC-7**, because the criterion is a slope in L (`beta_FDTD = -d(arg S21)/dL` from two line lengths, scope L266-268) taken on `s21.raw_phase_rad`: the de-embedded `s21.phase_deg` is de-embedded with each run's own measured beta (`emfit/ports.py:1707-1731`, called at `emfit/studies.py:3242`) and is therefore flat in L by construction, which the artefact records as a `phase_degeneracy` block precisely so that nobody can quote it as a beta; **Run B** (`--load-ohm 100`) closes nothing and is not an acceptance criterion at all — it is the exploratory arm of scope L520 Ruling 3 ("25 and 50 Ohm are graded against AC-3; 100 Ohm is exploratory"), reported by the grader as a band check on |S11| against |R - Zc|/(R + Zc), never as an AC passed or failed. What stays open, and is emitted with `achieved: None` and `closable_in_run_a: False` rather than scored on a proxy, is **AC-4** (needs at least two *unmatched* loads, scope L246-250) and the seam half of **AC-5** (needs an open control against a PML-terminated reference run in the same batch, scope L256-258); both are deferred to dispatch 2c. Cost, and it is a FLOOR rather than a measurement: the six field components alone are `6 x 8 B x cells` = **13.5 MB** on Run A (6 x 8 x 280,984 = 13,487,232 B) and **18.9 MB** on Run E (6 x 8 x 394,284 = 18,925,632 B). That arithmetic excludes the materials matrices, the edge lists and interpreter overhead, so a peak RSS is strictly larger and is **UNMEASURED** — as is the wall time, since no run of this build has ever been recorded (`evidence/termination/` holds no `build_A_50ohm.json` and no `build_E_50ohm.json`) — against the per-run 1400 s wall gate and the `--mem-ceiling-mb 2000` trip that both runs are launched under; a trip writes a `.trip.json` marker and exits 3 or 4, and a trip is not a licence to relaunch.
