# RUN.md - start the app
The one command, from the repository root: `PYTHONPATH=. python3 server/poc_app.py` (it serves http://127.0.0.1:8080/ and opens no browser).
That is the only instruction kept here: `docs/kb/WORK/run.md` is the maintained source, with flags, preflight, headless caveat, dependencies and known-broken items.
Do not add run instructions to this file - edit the WORK file instead, so one copy stays authoritative.
