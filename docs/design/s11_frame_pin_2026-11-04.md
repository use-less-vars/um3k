## 1. The question, and its numeric inputs

The s11 phase in every A arm is the station-plane reflection coefficient de-embedded to a port plane at `x_port = ix_port*cell = 8*0.4 mm = 0.0032 m` (`evidence/termination/run_build_A.py:1411`):

    ang(gamma_port) = ang(gamma_plane) - 2*beta*d,    d = x_plane - x_port

`beta` = `line.beta` = 286.35930483082825 rad/m (`beta_one`; `line.beta_two_wave` = 231.55331672912826). Recorded `s11.phase_deg` = -160.26362819520853 and `s11.magnitude` = 0.32556486641109117 in `evidence/termination/build_A_50ohm_v3_zeff.json` (n_line 64, ix_port 8, plane 51, cell 0.0004); un-de-embedding returns +76.0000 deg at the station plane.

The competing analytic TE phase is the single point ratio S11 = (Z-Z0)/(Z+Z0), Z0 = 47.54 ohm, applied to the measured load impedance, giving -21.9026 deg (`docs/design/complex_load_analysis_2026-11-04.md:147-151`). The two candidates for the plane that phase belongs to:

| frame | anchor x | d | 2*beta_one*d |
|---|---|---|---|
| **F1** station 0 | 0.0104 m (`MS_X_FIRST`) | 0.0072 m (18 cells) | 236.2634 deg |
| **F2** load | 0.0200 m (`geometry.loads[0].x`) | 0.0168 m (42 cells) | 551.2812 deg |

## 3. Verdict

**F2 - load-referenced, d = 0.0168 m.** The only impedance ever fed to the TE is the one measured across the E_z edges of the load's own node column (column 50, x = 0.0200 m; `studies.py:3070`, `:2394`, `z_eff_basis`), and (Z-Z0)/(Z+Z0) is a point ratio with no propagation term, so the phase it yields is the phase of gamma AT x = 0.0200 m. Pairing it with a port-plane phase requires d_load = 0.0168. No code path and no doc line places the TE at station 0; F1 exists only as the investigation doc's own hypothesis, introduced to explain how the beta substitution could hide.

Caveat, so the verdict is not over-read: the frame is recorded in no artefact field (DR-27; `s11_phase_investigation_2026-11-04.md:66`, `:173`), so this rests on code plus `_basis` prose, not on a recorded value. Re-pin if a TE is ever recomputed from a station-plane z.

## 4. Sensitivity - why the pin matters

The frame sets the size of the beta substitution term `2*(beta_one-beta_two)*d`: **45.2182 deg** at d_station, **105.5091 deg** at d_load, both against a **52.92 deg** signal under test (factor 0.85 against 1.99). Under F1 both legs share d_station and the difference cancels exactly (residual -97.90 for either beta); under F2 the legs split by 0.0096 m and 60.2909 deg survives. Section 5 of the investigation doc, and the case for `s11-estimator-fix-2026-11-04`, turn on this one choice. The beta test is frame-independent and should run either way.
