## 2. What would make this test mean something (written BEFORE the numbers)
The load sits at x = 20.0 mm; the used stations span 10.4-18.8 mm, so the nearest used station is 1.2 mm (3 cells, cell 0.4 mm) from the load plane, and dropping from the load end raises that to 2.4 / 3.6 / 4.8 mm (6 / 9 / 12 cells). **If the movement is load contamination** it must appear on the load side and NOT on the port side; **if it is a shorter-baseline / conditioning effect** it must appear equally on BOTH sides, because the lever arm over which forward and backward amplitudes are separated has shrunk by the same amount either way.
The two ladders' design matrices are bit-identical (`u = x - x[0]`, same values, same spacing), so any asymmetry between them is data and any equality is the model's own translation invariance plus data that look the same at both ends. n is stopped at 5: below 5 rows a two-wave fit (4 unknowns) leaves one degree of freedom and is not well-conditioned.

## 6. What this establishes, and what it does not
(a) The artefact's stated cause is **refuted for this record**: removing the near-load stations does not move `|gamma_v|` toward the anchor, and the port-side control moves it identically, so the residual is NOT load near-field contamination of the station fit. What it does not establish: why the excess exists (it is common-mode, so it is not in the load at all on this evidence), and nothing here touches `s21` or the twin arm.
(b) N1 did not fire, so **no host run is licensed by this result** and no parameter move is proposed: the briefed counterfactual (move the extraction plane / last station away from the load by a stated distance, e.g. 18.8 mm -> 16.4 mm, 6 cells, i.e. `--n-line` plus the station span and `--s21-plane-index` re-derived) would have been the confirming run for contamination; it is described here only to record that it is NOT what this evidence calls for. Per N2 the pivot is the V/I-definition (Zpi) test, or accept the residual.
